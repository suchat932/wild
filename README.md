# สัญลักษณ์ Wildcardsซ้อนกัน

```
* * * *
** ** **
*** *** ***
**** **** ****
***** ***** *****
```

## คำอธิบาย
- แถวที่ 1: wildcard 1 ตัว (*)
- แถวที่ 2: wildcard 2 ตัว (**)
- แถวที่ 3: wildcard 3 ตัว (***)
- แถวที่ 4: wildcard 4 ตัว (****)
- แถวที่ 5: wildcard 5 ตัว (*****)

แต่ละแถวมีการซ้อนกัน 4 ตัว
